# Data

The paper evaluates 3DSFF on named color images including Oakland, Splash, Mandrill, F-16, Sailboat, Peppers, and House. The supplied material did not contain those image files or a data manifest that uniquely identifies their source versions and preprocessing.

Place your own legally obtained test images under `data/raw/`. The paper-derived FSM reconstruction currently expects square power-of-two images (for example 256×256 or 512×512) and FQM requires even dimensions.

The repository includes `examples/assets/demo_64.png`, a deterministic synthetic image generated by `scripts/generate_demo_image.py`, only for unit tests and quick-start checks. It must not be interpreted as a reproduction of the paper's benchmark dataset.
