# Experiment Reproduction Guide

All commands below assume execution from the repository root after `pip install -e ".[dev]"`.

## Self-contained verification

```bash
pytest
python experiments/reproduce_core.py \
  --input examples/assets/demo_64.png \
  --config configs/paper_default.json
```

The synthetic 64×64 image is generated by `scripts/generate_demo_image.py` and is included only to test the software. It is not one of the paper's benchmark images.

## Section III-A — S-box security

Analyze the reconstructed S-box generated for an image:

```bash
python experiments/run_sbox_analysis.py \
  --input examples/assets/demo_64.png \
  --config configs/paper_default.json
```

Analyze the exact 16×16 S-box printed in paper Table I:

```bash
python experiments/run_sbox_analysis.py \
  --paper-table-i \
  --output results/generated/paper_table_i_sbox.json
```

The latter path is particularly useful for validating metric code independently of ambiguities in S-box generation. From Table I the implementation reproduces component nonlinearities `[106, 104, 102, 104, 102, 102, 102, 108]`, mean `103.75`, and standard SAC mean `0.501708984375` (paper comparison value `0.5017`). BIC-SAC is not claimed as exact because the paper does not give its computation formula.

## Section III-B — chaotic properties

```bash
python experiments/run_chaos_analysis.py
```

Outputs phase portraits, a `b`-parameter bifurcation plot, a p–q trajectory, QR/Benettin Lyapunov estimates, and a compact 0–1 statistic. The paper itself reports two inconsistent Lyapunov triplets; both are retained in the JSON output for auditing.

For NIST SP 800-22:

```bash
python experiments/export_nist_bitstream.py --length 1000000
```

Run the resulting byte stream through a trusted NIST STS implementation separately. The exact Table X p-values cannot be claimed because the paper omits bitstream preprocessing and suite settings.

## Section III-G — key sensitivity

```bash
python experiments/run_key_sensitivity.py --delta 1e-16 --axis x
```

The paper gives `d=10^-16` but does not say which one of the three initial states is changed. The script makes that choice explicit with `--axis` and plots both trajectories rather than hiding the assumption.

## Section III-C/G — differential and plaintext sensitivity

```bash
python experiments/run_differential_analysis.py \
  --input data/raw/Mandrill.png \
  --trials 50 \
  --seed 0
```

Each trial changes one randomly selected channel value by `+1 mod 256`, encrypts the modified plaintext, and compares its ciphertext with the baseline using NPCR and UACI.

## Section III-D/J — timing / deployment-oriented benchmark

```bash
python experiments/benchmark.py \
  --input data/raw/Mandrill.png \
  --repeat 3
```

The paper's reported timing is from MATLAB 2022b on Windows 11 / Ryzen 7-7745HX / 16 GB RAM. Python timings from another machine are expected to differ and are stored separately from the published Table XIV values.

## Section III-E — FSM round study

```bash
python experiments/run_iteration_study.py \
  --input data/raw/Mandrill.png \
  --max-rounds 25
```

This produces `ssim_by_round.csv` and a plot. Exact Fig. 9 reproduction is not claimed because the paper does not specify SSIM windowing.

## Section III-F — histogram, correlation, entropy

Encrypt first, then analyze the ciphertext:

```bash
threedsff encrypt \
  --input data/raw/Mandrill.png \
  --output results/generated/mandrill_cipher.png \
  --key-output results/generated/mandrill_key.json \
  --config configs/paper_default.json

python experiments/run_statistical_analysis.py \
  --input results/generated/mandrill_cipher.png
```

## Section III-H — chosen plaintext

```bash
python experiments/run_chosen_plaintext.py --side 256
```

This generates all-black/all-white plaintexts and their ciphertexts. It is a demonstration corresponding to Fig. 14; it is not an automated proof that every possible chosen-plaintext attack fails.

## Section III-I — robustness

```bash
python experiments/run_robustness.py \
  --input data/raw/Peppers.png
```

The script uses crop area ratios `12.5%` and `25%`, and salt-and-pepper densities `10%`, `20%`, and `30%`, matching the levels stated by the paper. Exact crop rectangles are not fully specified in the text and are therefore documented reconstruction choices.

## Published reference values vs generated results

- `results/paper_reference/`: values transcribed from the paper and never overwritten by scripts.
- `results/generated/`: local outputs; ignored by Git.
- `results/smoke/`: small self-contained validation artifacts generated during repository construction; **not** paper benchmark results.

This separation prevents accidental presentation of local/reconstructed outputs as published experimental measurements.
