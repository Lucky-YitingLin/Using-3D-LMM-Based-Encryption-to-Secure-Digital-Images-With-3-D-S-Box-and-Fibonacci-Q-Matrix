# Smoke verification snapshot

These JSON files were generated during repository construction with the included synthetic `examples/assets/demo_64.png`. They are retained only as evidence that the reconstructed code executed and passed basic checks; they are **not** results from the paper's benchmark images.

- `core/metrics.json` — exact encryption/decryption round trip plus synthetic-image ciphertext entropy/correlation.
- `generated_sbox_metrics.json` — metrics of the S-box generated by the reconstructed pipeline for the synthetic image.
- `paper_table_i_sbox_metrics.json` — metrics recomputed from the S-box transcribed directly from paper Table I.
- `chaos/metrics.json` — QR/Benettin and 0–1 diagnostic output from this implementation, including both inconsistent Lyapunov triplets printed in the paper for reference.

Timing values are machine/run dependent and are not used as paper reproduction claims.
