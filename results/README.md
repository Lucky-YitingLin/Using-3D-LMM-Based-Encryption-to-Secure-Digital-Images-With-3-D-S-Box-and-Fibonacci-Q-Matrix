# Results

Result files are deliberately separated by provenance.

- `paper_reference/` — numerical values transcribed from the supplied paper. These are reference data, not outputs generated by this implementation.
- `smoke/` — small local verification outputs generated with the included synthetic 64×64 image. They demonstrate reversibility and code execution only.
- `generated/` — normal experiment output directory. It is ignored by Git so repeated experiments do not pollute the repository.

Never compare a synthetic/smoke metric directly with a published table without matching the paper's image, dimensions, configuration, numerical conventions, and experiment protocol.
